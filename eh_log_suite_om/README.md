# Oman Logistics Suite

One-click install for the ERP Heritage logistics suite scoped to the
Sultanate of Oman on Odoo 19 Community Edition.

## What this module does

Meta module. No models, no views, no data of its own. Installing it
pulls in 17 engines plus 2 Oman-specific modules.

## What is included

**Engines (global)**

`eh_log_base`, `eh_log_quotation`, `eh_log_freight`, `eh_log_customs`,
`eh_log_transport`, `eh_log_dashboard`, `eh_log_carrier_portal`,
`eh_log_cold_chain`, `eh_log_container_mgmt`, `eh_log_dangerous_goods`,
`eh_log_disputes_variations`, `eh_log_edi`, `eh_log_last_mile`,
`eh_log_project_cargo`, `eh_log_ship_agency`, `eh_log_track_trace`,
`eh_log_warehouse_3pl`.

**Oman localisation**

* `eh_log_l10n_om` &mdash; Oman master data (Sohar, Salalah, Duqm
  ports, free zones).
* `eh_log_l10n_om_customs` &mdash; Bayan single window declaration
  submission and status, Royal Oman Police Customs hooks.
